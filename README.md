# 🎓 College Finder – JavaFX App

**College Finder** is a smart, JavaFX-based desktop application that helps students discover the best-fit colleges based on their entrance exam scores, preferences, and eligibility criteria. It evaluates over **50+ parameters** to recommend colleges and uses **Firebase** for data storage and user authentication.

---

### 🚀 Features

- 🔍 Search colleges based on score, stream, location, category, etc.
- 📈 Evaluates using 50+ academic and preference-based parameters
- 🔐 Firebase integration for user data and authentication
- 💾 Stores user sessions and history
- 💡 Clean UI using JavaFX with scene-based navigation
- 📊 Real-time filtering and smart suggestions

---

### 🧰 Tech Stack

- **Language:** Java  
- **UI Framework:** JavaFX  
- **Backend:** Firebase Realtime Database / Firestore  
- **Authentication:** Firebase Auth  
- **Build Tool:** Maven / Gradle (if used)
